About

Learning by building.

Mr. Matt STEM Tools is a collection of browser-based classroom projects designed around experimentation. The goal is simple: give students something they can manipulate, test, break, improve, and understand.

The tools are intentionally lightweight so they can run in a normal web browser and be linked directly from classroom assignments.
