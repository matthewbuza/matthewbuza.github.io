Simulated LED output
Brightness follows duty cycle
analogWrite(9, 128);

The LED is visually averaged because PWM pulses are too fast to distinguish by eye. Real LED brightness is not perfectly linear with perceived brightness.

What to notice

Duty cycle: Changes the proportion of each cycle spent at 5 V. The frequency stays the same.

Frequency: Changes how many pulses occur each second. At the same duty cycle, ideal average voltage stays the same.

Arduino connection

Use a PWM-capable pin → current-limiting resistor → LED → GND.

analogWrite(pin, value) uses values 0–255. This simulator assumes an unloaded 5 V digital output and default Uno timer settings.
