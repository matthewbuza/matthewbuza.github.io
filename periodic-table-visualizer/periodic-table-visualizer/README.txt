Model buttons switch without a reload or camera reset. A 300 ms outgoing-canvas
fade smooths the change; reduced motion disables it. Electron selections clear
across model boundaries. Nuclear selections remain when practical.

Controls
Mouse, one-finger touch, or stylus drag: turn the atom in the drag direction.
Wheel or two-finger pinch: zoom. On-screen +/- also zoom. Pitch is bounded;
there is no momentum. Focus canvas: arrows rotate, +/- zoom, Escape clears.
Reset View restores camera angle/zoom and clears selection. Pause/Resume controls
electron motion or wave/cloud pulsing without changing the camera. Labels hide
annotation text. Help closes with Escape. Hidden tabs stop frame scheduling.

Representative selection
Proton / Neutron choose a visible representative; direct nucleus clicks work
in all models. Missing categories are disabled with explanations.
Inner electron / Valence electron choose a particle in Bohr, an allowed wave
state in de Broglie, and an occupied orbital region in Schrödinger. A region
is not an additional particle. Clicking waves/clouds also selects regions.
Clear Selection resets region highlighting; in quantum view it restores Overview.

Schrödinger display modes
Overview is the default. It combines a grouped inner region with a limited set
of outer or chemically important regions, keeping the nucleus visible. This is
a teaching representation, not a calculated sum of electron density.
Explore Subshells isolates one occupied subshell. The list comes from the active
atom's electron data. Copper offers 1s, 2s, 2p, 3s, 3p, 3d, and 4s. The panel
shows electron occupancy, capacity (s:2, p:6, d:10, f:14), type, and shape.
S has spherical character, p paired lobes, d multiple lobes, and f more complex
lobes. One representative orientation is drawn in detail; the orbitals in a
subshell do not all share that orientation. Camera orientation is preserved.
Selecting a probability region opens Explore Subshells; Overview or Clear
Selection returns to the combined picture. No cloud is created per electron.
De Broglie also provides an occupied-level selector, with exact electron counts.

Explanation levels
Elementary / Middle School / High School is a labeled segmented selector.
High School is the default. app.state.level stores the choice, independent of
scientific data. Changes update model descriptions, particle explanations,
model comparisons, and definitions immediately, without changing camera/model.
The level persists during model switching, selection, and presentation.
explanations.js contains structured, reusable language for proton, neutron,
inner/valence electron, nucleus, shell, matter wave, orbital, and isotope, plus
basic element/ion/count definitions. Advanced scientific records stay separate.
Compare Models summarizes why different views help explain the same atom.

Atom-only presentation
Full Screen requests the browser Fullscreen API. When unavailable or denied,
the atom fills the current browser viewport instead. Both modes show only the
atom, current model name, and Exit Full Screen button. Labels, legends, panels,
header, and normal controls are hidden and excluded from keyboard focus.
Drag, pinch, wheel, and keyboard camera controls keep working. Animation state
is preserved. Exit Full Screen or Escape restores the full interface and the
camera angle/zoom saved on entry. Browser-initiated fullscreen exit is handled.
The selected model and explanation level do not change. Presentation changes
only the viewport; it does not start animation or add camera auto-rotation.

Element = proton count; neutron count = isotope mass number minus atomic number.
Electron count = atomic number minus signed ionic charge. Positive ions have
fewer electrons; negative ions have more. Isotope selection never changes charge.
Mass number counts nucleons, not the periodic table's weighted average mass.

survive. All cached renderers receive the new derived record; profile/accessibility

validated against shell populations and capacities; no guessed filling algorithm.
Future elements still require verified scientific records, element-specific
classroom wording where needed, and visual tuning. Orbital-level valence
chemistry is not automatically inferred from outer-shell occupancy.

Scientific limitations
This is a conceptual visualization, not a numerical quantum-mechanics simulation.
Nucleus, electron regions, distances, amplitudes, and speeds are not to scale.
Wave counts use an illustrative integer fit, not a many-electron copper solution.
Cloud angular envelopes suggest familiar orbital forms. Radial sizes, point
distributions, radial nodes, energies, and electron interactions are not solved.
The nucleus is drawn clearly in front of probability regions for inspection.
Cloud pulse is a visibility effect, not an oscillating ground-state density.
The overview groups inner density and uses qualitative important regions; it
does not claim that a filled subshell has one individual orbital’s lobed density.
Copper conduction is introduced in words only; no solid, bands, lattice, field,
drift, or current simulation is included. Phase 3 adds the conceptual nucleon interior described below.

PHASE 3 — INSIDE PROTONS AND NEUTRONS

Enter and return
Select a visible proton or neutron, then choose Explore Inside in the inspector.
The representative Proton/Neutron selector plus this button is the keyboard
alternative: Tab to the button and press Enter or Space. Double-click or double-tap
a visible nucleon also enters it. The first click selects and highlights normally.
Two releases on the same nucleon and pointer type, within 650 ms and 24 pixels,
count as a double activation. Movement over 5 pixels, a pinch, or cancellation
invalidates the sequence; dragging back to the starting point still counts as
a drag. Avoid double-tapping while trying to rotate; Explore Inside is available
when tapping small nucleons is difficult.

The transition lasts about 1.5 seconds, magnifying an image toward the selected
nucleon as atomic structures fade. Reduced motion uses a 180 ms fade. This is
not a physically accurate scale journey. Pointer gestures are ignored during
the brief entry transition. Back to Atom can cancel it safely.
The breadcrumb identifies Atom > Nucleus > Proton/Neutron. Back to Atom restores
the atomic model, saved camera, selected nucleon, subshell, and prior animation
pause state. The current explanation level carries back. Back to Nucleus returns
to the same atom model at a closer nuclear zoom (at least 3.2x).
Escape closes an open dialog first, otherwise returns from a nucleon to the atom.
There is no simulated conversion from a proton to neutron; return and select
another nucleon to compare their interiors.

Internal picture
Proton: up + up + down. Charge: +⅔ + +⅔ − ⅓ = +1.
Neutron: up + down + down. Charge: +⅔ − ⅓ − ⅓ = 0.
Neutral means the charges add to zero, not that the neutron has no charged parts.
The three prominent glowing regions are valence-quark teaching symbols. Up is
marked by a triangle, down by a diamond, with flavor and charge labels. They
shift locally and pulse; they do not orbit a central object or follow fixed paths.
A diffuse boundary suggests the nucleon region, not a hard enclosing shell.
Seven changing curves and sparse fluctuations represent gluon-field activity and
self-interaction. Curves are not wires, springs, or literal gluon trajectories.
At High School level, three subtle paired flickers represent short-lived
quark–antiquark activity. The full interior is not only three objects.
Drawing colors are decorative; no visual color-charge assignments are made.
The explanations distinguish color charge from visible color and describe
confinement and the contribution of internal energy to nucleon mass.

Controls inside
Drag/touch rotation, wheel/pinch zoom, keyboard arrows and +/-, Pause/Resume,
labels, and Reset continue to work. Internal zoom is limited to 0.65–2.5x.
Click/tap a quark region, gluon curve, or boundary to inspect it. Touch hit targets
are forgiving. Use the internal category selector for Up quark, Down quark,
Gluon field, or Whole proton/neutron. No numbered quark entries are exposed.
Clear Selection removes the highlight. Selection does not pause the animation.
Reset restores internal camera/zoom and clears component selection.

Elementary, Middle School, and High School levels update component descriptions,
charge guidance, mass, strong interaction, color charge, sea activity, comparison,
and limitations. Changing level preserves internal selection, camera, active
nucleon, animation, and presentation state. The comparison table is informational;
no dragging or beta-decay conversion is implemented.

Fullscreen
Enter fullscreen from a nucleon to present its interior. Entering a nucleon by
double activation while the atom is fullscreen keeps fullscreen active. The minimal
Back to Atom control returns without leaving fullscreen. Exit Full Screen leaves
the current scale open. Escape from inside returns to the atom first; another
Escape can exit presentation. Browser-native Escape handling may also leave
native fullscreen; the current scale remains navigable. The existing viewport
fallback works when Fullscreen API permission is denied or unavailable.

Data and resources
nucleon-data.js: immutable quark and nucleon records; exact rational charge
numerators in thirds; computed equation; reusable three-level explanations.
nucleon-model.js: dedicated conceptual renderer and its disposable drawing state.
subatomic.js: entry/return snapshots, transition, internal inspector, breadcrumbs.
Scientific atom records and its physical particle objects are never modified
by exploration. Quark/field drawing components are separate from atom particles.
Exact integer addition in thirds produces +1 or 0, never rounding artifacts.
The internal renderer reuses its small component set and caps pixel ratio at 2.
It draws 7 curves with 40 samples (24 in reduced detail), 18 field specks, and
at most 3 flicker pairs. Returning disposes component/hit arrays, transition
snapshots, and callbacks; the existing three atomic renderers remain cached.
Tab visibility and reduced-motion behavior are inherited from the application.

Limitations
This is a conceptual animation, not numerical quantum chromodynamics (QCD), the
theory of the strong interaction. Sizes, localized regions, motions, curves,
colors, boundary, and flickers are teaching choices, not literal footage or
physical paths. No free quarks, beta decay, weak bosons, other quark generations,
mesons, or additional hadrons are simulated. Real nucleon dynamics are more complex.
Modern browser support and offline launch requirements remain unchanged.
Physical touch/stylus devices and non-Chrome browsers still need classroom testing.
See TEST-RESULTS.txt for actual verification and limitations.


PHASE 4 — COPPER ISOTOPES

Use the selector beside the stability label in the atom profile. Stable copper-63
and copper-65 have 34 and 36 neutrons. Radioactive copper-64 and copper-67 have
35 and 38 neutrons. Neutrons = mass number minus 29. Every neutral selection
retains 29 protons, 29 electrons, and shells 2/8/18/1.

Changing isotope regenerates the nucleus and updates all cached atomic renderers.
Electron objects, model, level, camera, and atomic viewing settings survive.
Nuclear selections clear safely. A change from inside a nucleon returns to the
atom first. A short outgoing-image fade is omitted with reduced motion.

Stable and radioactive options are grouped and labeled in words; a radiation
symbol also identifies radioactive records. Stable records have no radioactive
half-life. Copper-64 has a 12.7-hour half-life and positron, beta-minus, and
electron-capture decay modes. Copper-67 uses IAEA's rounded 62-hour half-life
(approximately 2.58 days) and beta-minus decay. No individual decay or half-life
animation is implemented. Half-life explanations describe large groups.

The abundance bar compares only stable copper-63 (69.15%) and copper-65 (30.85%).
These are typical terrestrial proportions and can vary slightly in natural
materials. Measured isotope masses, not integer mass numbers, give the weighted
average near 63.546. The bar is hidden for radioactive selections.

Cosmic context is separate: copper is much rarer than hydrogen and helium; stars
and stellar explosions contribute to its production. Earth fractions are not
universal cosmic fractions. No reliable universal copper-isotope percentage is
asserted from these sources. Nine isotope concepts have three explanation levels.

Ordinary industrial copper is generally a mixture, not isotope-separated metal.
Copper-64 supports PET/tracer applications and therapeutic research. Copper-67
is investigated for targeted radionuclide therapy, with accompanying gamma
radiation useful for imaging. Applications depend on the prepared compound;
these statements do not claim blanket treatment approval or imply ordinary
copper products are medical radioisotopes. Nuclear drawings remain conceptual.

PHASE 4.5 — GENERALIZED ENGINE

Hydrogen through argon and copper are the nineteen completed student-facing explorers.
Copper-63 remains copper’s default and all four copper isotopes are retained. Phase 5 added the periodic
table home page described above.

Element, isotope, ion, and viewing state stay separate. A validated element and
isotope plus signed ion charge and explicit electron structure produce a frozen
scientific atom. Geometry and renderers derive from that atom. Camera, selection,
model, explanation level, pause, and presentation are mutable viewing state only.
Element records support family, period, group, block, full/shorthand configuration,
shells, occupied subshells, outer shells, chemically important subshells, useful
isotopes, classroom descriptions, and optional notes/warnings. No filling order
is guessed for ions. Isotope changes preserve ionic charge and electron objects.

engine-config.js centralizes capacities, display radii, framing, validation and
complexity. engine-ui.js adds loadAtom, dynamic choices and display-mode controls.
The renderer no longer assumes 29 particles, four shells, one outer electron,
seven occupied subshells, 4s valence, or a fixed copper-sized drawing frame.
Neutral uranium validates 92 electrons across seven shells and 18 subshells.
Copper's 3d/4s teaching note belongs to its record, not its renderer.

Light: atomic number <=10 and mass <=30. Medium: larger, until mass >150 or
more than 12 occupied subshells selects Heavy. Heavy nuclei use flat disks,
smaller electron markers, fewer wave segments and a lower pixel-ratio cap.
All tiers limit Overview to at most four layers. Exact nucleon/electron objects
remain present. Nuclear sites form a perturbed, rotated compact cluster; these
are illustrative positions, not a nuclear structure calculation. Replaced
renderers dispose their particle, hit, cloud, sprite, and focused-cloud arrays.

About These Models, near the model controls, explains scale, rings, waves,
probability pictures, grouping, subshell exploration and illustrative nuclear
positions in Elementary, Middle School and High School language.

Internal tests: open tests/atom-engine-test.html directly. The five choices are
Hydrogen-1 (1p/0n/1e), Carbon-12 (6/6/6), Copper-63 (29/34/29),
Xenon-132 (54/78/54), and Uranium-238 (92/146/92). Hydrogen disables Neutron
with an explanation. Uranium is radioactive; the other four test isotopes are
stable. All use the normal controls, model renderers and nucleon interiors.
Calculated totals, validation, object counts and a draw-time benchmark are shown.
Invalid input identifies the record/field and retains the working atom.
Return to Copper provides recovery. A failed detailed shape falls back to
Overview with an explanation and retains accurate scientific text.

Read DEVELOPER-NOTES.txt for record schemas, sources/access dates, architecture,
and the future periodic-table entry point. The engine is ready to integrate
that entry point for validated records; the other 113 elements and finished
classroom explanations still require data verification and visual QA.

Limitations: qualitative angular forms, illustrative radial sizes, no exact
wavefunction/density/nuclear calculation. Overview does not render every orbital
simultaneously. Heavy-atom internal nucleons can be obscured; representative
selection prefers visible surface nucleons. Electron categories identify an
outer representative, not a claim that only outermost shells affect chemistry.
Measurements describe this desktop Chrome environment only; no Chromebook,
physical tablet, or assistive-technology testing is claimed.
